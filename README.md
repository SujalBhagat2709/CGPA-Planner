# CGPA Planner

## Overview

CGPA Planner is a Python command-line application that helps students manage their academic performance. It records semester GPAs and credits, calculates the current CGPA, predicts future CGPA, estimates the GPA required to reach a target CGPA, and provides an academic summary.

---

## Features

- Add Semester Records
- Calculate Current CGPA
- Predict Future CGPA
- Calculate Required GPA for Target CGPA
- Academic Summary
- Display Semester Records
- Interactive Menu
